# Feedback

Thanks for using Stratum. Here's how to get in touch.

## Quick decision tree

| You want to... | Use... |
|---|---|
| Report a bug | [Bug report](https://github.com/digitalities/stratum-ns3/issues/new?template=bug.yml) |
| Request a feature | [Feature request](https://github.com/digitalities/stratum-ns3/issues/new?template=feature.yml) |
| Ask "how do I X?" | [ns-3 mailing list](https://groups.google.com/g/ns-3-users) for general ns-3 questions; [GitHub issue](https://github.com/digitalities/stratum-ns3/issues) for Stratum-specific ones |
| Suggest a recipe | [Recipe request](https://github.com/digitalities/stratum-ns3/issues/new?template=recipe-request.yml) |
| Tell us you used Stratum in your work | [Used-in-work report](https://github.com/digitalities/stratum-ns3/issues/new?template=used-in-work.yml) — high-signal feedback we love receiving |

> **Note:** issue templates for bug/feature/recipe-request/used-in-work ship with the repository. The config template (`config.yml`) gates the new-issue flow.

## Citation

If you use Stratum in your work, please cite it. Three options of increasing fidelity:

- **Easiest**: click "Cite this repository" at the top of the GitHub repo page — uses the metadata from [`CITATION.cff`](../CITATION.cff).
- **BibTeX (software)**:
  ```bibtex
  @software{stratum-ns3-2026,
    author    = {Andreozzi, Sergio},
    title     = {{Stratum: A QoS Substrate Composing DiffServ, L4S, and CAKE in ns-3}},
    year      = {2026},
    version   = {v1.1},
    url       = {https://github.com/digitalities/stratum-ns3}
  }
  ```
  A DOI will be minted if the paper is accepted for publication; the `doi` field will be added to `CITATION.cff` at that point.
- **Paper (when published)**: submitted to ICNS3 2026 — citation will appear here on publication.

The 2001 thesis that provides the DiffServ4NS intellectual lineage is deposited on Zenodo:
[10.5281/zenodo.19662899](https://doi.org/10.5281/zenodo.19662899) (concept DOI) /
[10.5281/zenodo.19662900](https://doi.org/10.5281/zenodo.19662900) (version DOI).
A Zenodo deposit for the ns-3 substrate itself is planned for camera-ready; until then, cite the GitHub repository above.
