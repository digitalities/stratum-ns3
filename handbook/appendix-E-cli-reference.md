# Appendix E — Command-line reference

> Generated by `scripts/gen-cli-reference.py` from each example's ns-3
> `--PrintHelp` output. Do not hand-edit — run the generator to refresh.

Every example self-documents its options at the terminal:

```bash
./ns3 run "<example> --PrintHelp"
```

This appendix is a snapshot of that output for the runnable examples. For what each example *does*, see the [examples catalogue](I-08-examples-catalog.md); for options whose values are themselves a catalogue, pass `--<flag>=list` (for example `--aqm=list`, `--scheduler=list`).

| `--l2OverheadBytes` | `4294967295` | L2 framing overhead bytes per packet on the bottleneck link. Default: auto-detect from the netdev via Helper::DetectL2OverheadBytes (PointToPoint -> 2 PPP, Csma -> 14 Ethernet, others -> 0). Pass an explicit non-default value to override (e.g. 0 to force pure IP-byte accounting, or a higher value to model additional framing like LLC/SNAP/VLAN/FCS). |
